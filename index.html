KeypadCraft

A block-building game for keypad phones. Isometric blocks, random worlds, 24 block types.

Install help

  • APK: open the downloaded file and allow "install unknown apps" for your browser when Android asks. It is a debug-signed build for personal use.
  • JAR: open it with J2ME Loader (Android) or another J2ME emulator, or send it to a Java phone.
